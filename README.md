# LiveCap · כתוביות חיות · רוסית ← עברית

דובר אחד מדבר ברוסית, מאזינים רבים קוראים כתוביות בעברית בזמן אמת.

## איך זה עובד
1. הדובר פותח `/speaker.html` בכרום ולוחץ על המיקרופון.
2. הדפדפן מזהה דיבור ברוסית (Web Speech API, חינמי) ושולח טקסט לשרת ב-WebSocket.
3. השרת מתרגם לעברית (Google translate endpoint, עם MyMemory כגיבוי) ומפיץ לכל המאזינים בחדר.
4. המאזינים פותחים `/l/קוד` ורואים כתוביות חיות, עם הגדלת טקסט, הצגת המקור והקראה קולית.

## פריסה ב-Render
1. העלה את התיקייה ל-GitHub.
2. Render → New → Blueprint (או Web Service) → בחר את הריפו. `render.yaml` כבר מוגדר.
3. אין משתני סביבה ואין מפתחות API.

## הערות
- בתוכנית החינמית של Render השרת נרדם אחרי חוסר פעילות, והפתיחה הראשונה לוקחת כחצי דקה.
- זיהוי הדיבור עובד ב-Chrome (אנדרואיד ודסקטופ). ב-Safari/Firefox התמיכה חלקית או חסרה.
- נקודות הקצה החינמיות לתרגום אינן רשמיות ועלולות להיחסם בעומס. אם צריך יציבות, מחליפים את `translate()` ב-`server.js` ל-DeepL או ל-Claude API.

## בדיקה מקומית
```
npm install

```
